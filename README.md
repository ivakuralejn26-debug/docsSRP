## 1. Как добавить нового персонажа

В файле по пути `/characters/index.json` впишите в квадратные скобки имя вашего персонажа. Для примера возьмём Гари Менгеля:

```json
["gary"]
```

Если хотите добавить ещё одного персонажа, перечислите имена через запятую:

```json
["gary", "mari"]
```

Теперь переходим в папку `/characters/` и создаём папку с именем вашего персонажа.

> **Важно:** папка должна называться точно так же, как имя персонажа в `index.json`. Например, для Гари папка будет называться `gary`.

Переходим в созданную папку, создаём файл `data.json` и вписываем в него следующее:

```json
{
  "id": "",
  "name": "",
  "alive": ,
  "status": "",
  "fields": [
    ["ОБОЛОЧКА", ""],
    ["ФРАКЦИЯ", ""]
  ],
  "sections": [
    {
      "title": "ПРЕДЫСТОРИЯ",
      "text": "",
      "placeholder": true
    }
  ]
}
```

Это и есть шаблон анкеты. Пример заполнения для Гари:

```json
{
  "id": "REC-000",
  "name": "Гари Менгель",
  "alive": true,
  "status": "Жив",
  "fields": [
    ["ОБОЛОЧКА", "Гештальт"],
    ["ФРАКЦИЯ", "Штрафник"]
  ],
  "sections": [
    {
      "title": "ПРЕДЫСТОРИЯ",
      "text": "Украл сухпаек, из-за чего попал в штрафники",
      "placeholder": true
    }
  ]
}
```

 Поздравляю, анкета создана!

## 2. Работа с таблицей

Вся работа ведётся в файле `/characters/ИмяВашегоПерсонажа/data.json`.

### 2.1 Как добавить новую строку в таблицу

Под значением `"fields"` (шестая строка) пишем новую строку в таком формате. Например, добавим группу крови:

```json
["Группа крови", "II"]
```

Так выглядит полностью:

```json
  "fields": [
    ["ОБОЛОЧКА", "-"],
    ["ФРАКЦИЯ", "-"],
    ["МЕСТО РОЖДЕНИЯ", "-"],
    ["Дата РОЖДЕНИЯ", "00.00.0000"],
    ["Группа крови", "II"]
  ],
```

Надеемся, всё понятно!

### 2.2 Как изменить цвет строки «СТАТУС»

За статус отвечают две переменные: `"alive"` и `"status"`.

- Переменная `"alive"` отвечает за **цвет**, которым будет гореть текст в переменной `"status"`.
- Если в `"alive"` написано `true`, текст в `"status"` будет **зелёным**.
- Если в `"alive"` написано `false`, текст в `"status"` будет **красным**.

## 3. Как добавить в анкету фото

В папку вашего персонажа кладём фото в формате `.jpg` с названием, совпадающим с названием папки персонажа.

Пример для Гари: `gary.jpg`
/characters/gary/gary.jpg

## 4. Как добавить новые строки по типу предыстории

Открываем файл `/characters/ИмяВашегоПерсонажа/data.json`. В переменной `"sections"` находится блок, например:

```json
  "sections": [
    {
      "title": "ПРЕДЫСТОРИЯ",
      "text": ""
    }
  ]
```

Чтобы добавить новую секцию (например, «Внешность»), впишите её через запятую после предыдущей:

```json
  "sections": [
    {
      "title": "ПРЕДЫСТОРИЯ",
      "text": ""
    },
    {
      "title": "Внешность",
      "text": ""
    }
  ]
```
